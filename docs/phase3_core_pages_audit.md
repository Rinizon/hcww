# Phase 3 Core Marketing Page Audit

This audit compares the current core pages against the Phase 3 goal in `docs/phases.md`.

Phase 3 goal:

- build the high-priority pages that explain the business clearly
- create a complete visitor path from first impression to contact
- ensure the homepage, About, Services, and Contact pages work together as a marketing funnel

## Overall Assessment

Phase 2 completed the visual system and core copy direction well. The current site already looks credible and communicates the business clearly.

The main Phase 3 work has now been completed around page behavior and funnel clarity:

- strengthening internal pathways between pages
- filling content gaps that previously required visitors to infer too much
- making each core page better at handing the visitor to the next best action

Remaining gaps now sit mostly in Phase 4 territory:

- dedicated service detail pages
- richer service-specific routing once those pages exist
- operational contact-form behavior

## Homepage

### Intended purpose

- introduce the brand
- build trust quickly
- guide visitors into services or contact

### Current strengths

- strong hero and value proposition
- clear enterprise-plus-local trust framing
- good service snapshot
- visible final CTA
- service area is already represented

### Remaining gaps

- no service-detail destinations yet beyond anchored overview routing
- homepage still depends on Phase 4 for deeper mid-funnel service detail paths

### Recommended follow-up

- keep homepage routing aligned with upcoming Phase 4 service pages

## About Page

### Intended purpose

- build trust through background, values, and local roots

### Current strengths

- founder story is present
- mission and values are clear
- relationship-driven tone is strong
- CTA is direct and appropriate

### Remaining gaps

- the page could eventually benefit from founder imagery when assets are available
- service-detail cross-links can become more specific once Phase 4 pages exist

### Recommended follow-up

- add imagery later when approved assets are available
- link into dedicated service pages once they exist

## Services Page

### Intended purpose

- provide a clear overview of offerings
- help visitors identify the right starting point

### Current strengths

- the three service categories are easy to scan
- plain-English positioning works well
- the process section reduces some friction
- CTA is clear

### Remaining gaps

- there are still no dedicated service-detail routes yet
- later FAQ or detail-page routing can deepen the mid-funnel path further

### Recommended follow-up

- build the dedicated service pages in Phase 4
- add richer routing once those pages exist

## Contact Page

### Intended purpose

- make it easy to get in touch
- reduce hesitation around outreach

### Current strengths

- low-pressure tone is strong
- contact methods are easy to scan
- the page explains what to ask and what happens next

### Remaining gaps

- the form is still static and non-submitting, which is acceptable for Phase 3 but means the conversion path is not fully operational
- no scheduling option is present yet
- operational inquiry handling still belongs to the later conversion phase

### Recommended follow-up

- implement working form behavior in the later conversion and operations phase
- decide whether scheduling should be added at launch

## Priority Order

Recommended implementation order that guided the completed Phase 3 build:

1. Homepage journey refinement
2. Services overview improvement
3. About page trust expansion
4. Contact page conversion clarity
5. Funnel-wide validation and Phase 4 dependency capture

## Phase 4 Dependencies Already Visible

These gaps should not be forced into Phase 3, but they are now clearly defined:

- dedicated service detail pages for website work, managed IT, and consulting
- richer service-specific CTA routing from homepage and Services page
- deeper pricing-to-service cross-linking once the detail pages exist
- stronger mid-funnel paths that point visitors to the correct detailed service page
