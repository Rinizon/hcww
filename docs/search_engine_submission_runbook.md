# Search Engine Submission Runbook

This runbook covers the first search-engine submission steps for the live Hill Country Web Works site.

## Sitemap URL

Submit this sitemap:

- `https://hcww.net/sitemap.xml`

## Google Search Console

Recommended property type:

- `Domain` property for `hcww.net`

Suggested steps:

1. Open Google Search Console.
2. Add the `hcww.net` property if it is not already present.
3. Complete the DNS verification flow if prompted.
4. Open the `Sitemaps` section.
5. Submit `https://hcww.net/sitemap.xml`.
6. Confirm that Google accepts the sitemap without errors.

## Bing Webmaster Tools

Recommended property:

- `https://hcww.net/`

Suggested steps:

1. Open Bing Webmaster Tools.
2. Add the `hcww.net` site if it is not already present.
3. Complete verification if prompted.
4. Open the sitemap submission area.
5. Submit `https://hcww.net/sitemap.xml`.
6. Confirm that Bing accepts the sitemap without errors.

## Completion Criteria

This setup should be considered complete when:

- the site is added to Google Search Console
- the site is added to Bing Webmaster Tools
- `https://hcww.net/sitemap.xml` is submitted in both tools
- neither tool reports a basic submission error

## Follow-Up

After the initial submission is complete:

- monitor indexing and crawl feedback in both tools
- review any reported crawl errors or exclusions
- resubmit the sitemap after major content expansions if needed
